拡散は量子になれるか 足せない級数と、越えられない節 ── どちらも「曖昧さ」が物理量だった

2026-10-27 ／ 第7回の末尾の二本の線を掘る。Nelson の確率力学はどこで切れるか、発散級数は本当に足せないのか。検証は付録に
四行の要約
  1. 拡散は一時刻の量子力学を正確に再現する（Nelson 1966）。重ね合わせの振動する密度を、D = ħ/2m の拡散過程が 0.5% で追う。
  2. 二時刻の相関で切れる。 波動関数の節は越えられない峠で、拡散はそこで分断される（エルゴード性の破れ、第1・4回）。量子力学は位相を持つので分断されない。
  3. 切れる理由は定理になる。 正の確率ではどうやっても再現できず、再現できるのは位相空間の負の確率（Wigner 関数）だけ。節の正体は負の確率である。
  4. 発散級数は「足せない」のではなく「そのまま足してはいけない」。 Borel 和は g = 1 でも 12〜16 桁出る。不安定な側では和の曖昧さが崩壊率そのものになり、積分でも量子力学でも比 1.000 で一致した。

01拡散は、一時刻なら量子になれる

Nelson (1966) の確率力学：粒子は拡散係数 D = ħ/2m のブラウン運動をし、速度場は波動関数から b = (ħ/m)[Re + Im](∇ψ/ψ) で決まる（流れの速度 + 浸透圧の速度）。すると粒子の密度が |ψ(x,t)|² に一致する、というのが定理である。第1回のウィック回転が「虚時間の拡散 = 量子力学の静的な量」だったのに対し、こちらは実時間の拡散で動く密度を追う。

02二時刻で切れる

励起状態 ψ₁ は x = 0 に節があり、二つの山に分かれている。粒子を片方の山から出し、二時刻の相関 C(t) = ⟨x(t)x(0)⟩ を測る。量子力学の対称化した相関は Re⟨1|x(t)x(0)|1⟩ = (|x₁₀|² + |x₁₂|²) cos t = 1.5 cos t。

Nelson の値は片方の山の平均の二乗 (2/√π)² = 1.273 に落ち着く。節を跨いだ粒子は数値の漏れで、刻みを 1/5 にすると 1.9% → 0.4% に減る（連続極限ではゼロ）。

量子力学の相関は振動して符号を変える。粒子は節を越えられないので、相関は正のまま。一時刻では同じ、二時刻では別物。節は第1回・第4回でいう「越えられない峠」で、拡散はそこでエルゴード性を失う。量子力学が失わないのは、位相を持つからである。Nelson 自身も 2005 年の「確率力学の謎」でこの立場を離れた。

03なぜ切れるか：節は負の確率

切れ目は Nelson の作り方の欠陥ではなく、正の確率全体に対する定理である。

定理（自明）
定常な実の確率過程について、Cauchy–Schwarz より |C(π)| ≤ C(0)。等号は x(π) = −x(0) がほぼ確実に成り立つときに限る。量子力学は C(π) = −C(0) を要求するので、どんな正の確率過程も、時間 π でちょうど符号を反転する決定論的な写像を含まなければならない。連続な拡散にはできない。

では何ならできるか。位相空間 (x, p) で古典的な振動子の流れ x(t) = x cos t + p sin t を使い、初期分布に Wigner 関数 W(x,p) を取ると、一時刻の密度も二時刻の相関も量子力学に一致する（二次のハミルトニアンでは厳密）。ただし ψ₁ の Wigner 関数は原点で負（W(0,0) = −1/π）で、負の体積は 0.21 ある。

符号つきの Wigner 関数だけが、節（ρ(0) = 0 がすべての時刻で保たれること）と相関の両方を満たす。負の部分を切ると節が埋まり、正の積分布は相関は出せるが π/4 で節が埋まる。Hudson (1974) の定理 ── Wigner 関数が非負なのはガウス状態だけ ── がこの表の中身で、節の正体は位相空間の負の確率である。拡散が量子になれないのは、負の確率を持てないからだ、と一行で言える。

05曖昧さ = 崩壊率（Stokes 現象）

g < 0 ではポテンシャルが下に開き、状態は不安定になる。このとき Borel 変換に実軸上の特異点が現れ、ラプラス積分の路をその上に避けるか下に避けるかで、和の虚部の符号が変わる。この曖昧さは欠陥ではなく、トンネルによる崩壊率を運んでいる、というのが resurgence の主張である。積分と量子力学の二段で確かめた。

核心
摂動級数の「足し方の曖昧さ」は、そのまま非摂動的な崩壊率である。級数は非摂動の情報を欠いているのではなく、曖昧さという形で持っている。超準解析の言い方なら、超有限和の標準部分が一意に決まらないとき、その不定性自体が物理量になる。

06二本の線は同じ型

この回の二本は、別の話に見えて同じ主張をしている。

07正直な線

どこで線が切れるか
  • Wigner の流れが厳密なのは二次のハミルトニアンまで。 非調和な系では Moyal 方程式に ħ² の補正が入り、古典流では再現できない。「節 = 負の確率」の読みは一般に成り立つ（Hudson）が、「古典流 + 符号」で全部出るのは振動子だけ。
  • Cauchy–Schwarz の議論が使えるのは定常状態。 非定常な重ね合わせでは C(π) = −C(0) の形の制約はなく、Nelson 過程がどこまで合うかは別途の問題。
  • resurgence の完全な形（instanton–anti-instanton の寄与が Borel の曖昧さを打ち消す）は見ていない。 ここで確かめたのは、曖昧さと崩壊率が等しいところまで。二重井戸で非 Borel 可和な級数が instanton 対で治る話（Zinn-Justin）は次の段。
  • Borel–Padé の精度は Padé の次数と級数の次数で決まる。 場の理論の級数は数次しか分からないことが多く、同じ精度は出ない。
  • 最初に書いた側方 Borel 和は積分路の指数を間違えていて、虚部が 70 倍ずれていた。 直して出し直した。
  • 第6回 の「同じ型」は語り。 正の確率の不足と Borel 可和性の不足を結ぶ定理は知らない。
まとめ
  • 拡散は一時刻の量子力学を再現し、二時刻で切れる。切れる場所は節で、正の確率では埋められない。節の正体は Wigner 関数の負の部分。
  • 発散級数は Borel 和で足せる（積分で 45 桁、量子力学で 16 桁）。不安定な側での和の曖昧さは崩壊率そのもので、量子力学で比 1.000。
  • 二本とも「正の実数で閉じない部分が物理量」という同じ型。
