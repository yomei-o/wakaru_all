01設計：サンプリングの壁を外す

第10回の符号問題には二つの顔があった。負の重みをサンプリングできないこと（統計の壁）と、拡散が節を越えられないこと（表現の壁）。ニューラル量子状態（第2回のヘリウムの系統）は、波動関数をネットワークで表して変分法で学習する。ここではサンプリングを一切せず、状態ベクトル全体（S_z = 0 の 12,870 成分）でエネルギーを厳密に計算して最小化する。残るのは「符号を表現できるか、学習で見つけられるか」だけになる。

系は J₁–J₂ ハイゼンベルク鎖（16 サイト、周期的）。J₂ = 0 では Marshall の符号則（A 副格子の上向きスピンの数の偶奇）が基底状態の符号を厳密に与える。J₂ = 0.5 は Majumdar–Ghosh 点で基底状態が厳密なダイマー積（符号則は依然正しい）。J₂ = 0.8 ではフラストレーションで符号則が壊れる。ネットワークは 16 → 24 → 24 → 出力の MLP（1033 パラメータ、12,870 次元より十分小さい）。

  • A：符号を持てないと 60% 外す。 正の波動関数で出せる最良は、符号の制約のない「ボソン的」な状態で、第10回の拡散がボソンに崩れたのと同じ。
  • B：符号を教えれば 4〜6 桁。 J₂ = 0.5 で 10⁻⁶ は、符号則が厳密なら振幅はごく単純（ダイマー積）だから。1033 パラメータで 12,870 成分を 6 桁で表している。
  • C・D：学ぶと 7〜19%。 位相として学ぶ D の方が実の符号を学ぶ C より一貫して良い。実の符号は不連続で、勾配が流れにくい。
  • J₂ = 0.8：教えた符号が間違いなら、学ぶしかない。 B は 33% に崩れ、D の 7.3% が最良。

03外れた予言：教えてから学ぶ

第10回の表（固定節 → 解放節）の順序から、「近似の符号則を教えてから複素の補正を学ぶ E が、J₂ = 0.8 で B と D の両方に勝つ」と予言して走らせた。結果は 8.4% で、D の 7.3% に負けた（J₂ = 0 では B と同じ 1.2×10⁻⁴）。

読み：間違った符号則は、出発点ではなく罠になる。ネットワークは教えられた符号を打ち消すところから始めなければならず、ゼロから位相を学ぶより遠回りになった。固定節法で「悪い節は良い節より悪い」のと同じで、近似の節を与えることが常に得とは限らない。ただし 3000 ステップ・一つの初期化での比較で、学習率や初期化を変えれば逆転する可能性はある。

04三つの節は同じ節

拡散・サンプリング・学習の三つで、障害は同じ一つの節である。違うのは「節を越える手段」で、拡散には負の確率、サンプリングには双対表現、学習には複素の位相が、それぞれの扉になっている。

05正直な線

どこで線が切れるか
  • サンプリングを外しているので、符号問題そのものは扱っていない。 測ったのは表現と最適化の難しさだけ。実際の NQS では C・D の上にモンテカルロの統計誤差が乗る。
  • 1 回の学習、1 つの初期化、3000 ステップ。 C・D・E の 7〜19% は最適化の失敗を含み、どこまでが表現の限界かは分けられていない。長く回す・初期化を変えると数字は動く。
  • N = 16 の鎖。 2 次元の J₁–J₂ 模型（符号構造が本当に難しい場所）ではない。
  • E の予言は外れた。 「教えてから学ぶ」が一般に悪いとは言えないが、少なくともこの設定では、間違った符号は出発点にならなかった。
  • 「三つの節は同じ節」は語り。 拡散の節・計算の節・学習の節を結ぶ定理はない。同じ波動関数の同じ零点を、三つの方法が別々に踏んでいる、という観察まで。
まとめ
  • 符号は本体：持てないと 60%、教えれば 10⁻⁴〜10⁻⁶、学ぶと 7〜19%。
  • 教えた符号が間違いなら、学ぶしかない。「教えてから学ぶ」は勝てなかった。
  • 拡散・計算・学習で節は同じ一つで、扉がそれぞれ違う：負の確率、双対表現、複素の位相。
