CNN で物理を計算する カーネル・深さ・チャンネル・対称性 ── 四つの部品の物理での名前

2026-10-19 ／ 第1回「c はどこにでもいる」の続き。数値はすべてこの日に回したもの（3D はビルド機の RTX 3090）

第1回 で二つの線を引いた。CNN の深さは熱方程式の時間で、熱方程式の時間を虚数にするとシュレディンガー方程式になる。この二本をつなぐと、「畳み込みを何層も重ねることでスペクトルが出る」はずである。やってみると、CNN の部品（カーネル・深さ・チャンネル・格子の対称性）は、どれも物理の言葉で名前が付いていた。

01カーネル = 分散関係

核心
畳み込みは平行移動と可換な線形操作なので、平面波 \(e^{ikx}\) を固有関数にもつ。その固有値（カーネルのフーリエ変換）が、物理でいう分散関係そのものになる。

1 次元の 2 階微分カーネル \([1,-2,1]\) に平面波を通すと、固有値は \(-2(1-\cos ka)\) になる。これは原子が一列に並んだ結晶の格子振動 \(\omega^2 = \tfrac{2K}{m}(1-\cos ka)\) である。

計算同じカーネルを、時間 1 階と 2 階で回す
回し方方程式測ったもの測定カーネルから
時間 1 階\(u_t = \text{conv}(u)\)：拡散\(\langle x^2\rangle/2t\)1.00001.0000
時間 2 階\(u_{tt} = \text{conv}(u)\)：波波束の速さ（k=0.3）0.98910.9888

拡散係数 D も音速 c も、カーネルの 2 次モーメントから出る換算係数である。二次の換算になるか一次の換算になるかは、時間微分の階数だけで決まる。

チャンネル = バンド。 質量 \(m_1, m_2\) が交互に並ぶ鎖は、2 チャンネルの畳み込みになる。カーネルは 2×2 の行列で、そのフーリエ変換の固有値が音響モードと光学モードの 2 本のバンドになる。格子を直接対角化した 128 モードとの差は最大 \(7\times10^{-15}\)。ギャップの端は \(\sqrt{2K/m_2}=0.8165\) と \(\sqrt{2K/m_1}=1.4142\) で、比は無次元量 \(\sqrt{m_2/m_1}\) だけで決まる。

02深さ = 虚時間 → スペクトル

シュレディンガー方程式を虚時間で書くと熱方程式になる。1 層を「虚時間を \(\delta\tau\) 進める」操作にすると

$$\psi \;\leftarrow\; \psi - \delta\tau\,\big(\underbrace{\text{conv}(\psi,\,[-\tfrac12,\,1,\,-\tfrac12]/h^2)}_{\text{運動エネルギー}} + \underbrace{V\cdot\psi}_{\text{点ごとの積}}\big)$$

層を重ねるほど高い準位が \(e^{-E\tau}\) で速く消え、基底状態が残る。チャンネルを \(K\) 本にして互いに直交させれば、下から \(K\) 個の準位が同時に出る。

計算二原子分子の振動（Morse ポテンシャル \(D(1-e^{-ax})^2\)、D=20, a=1）、5 チャンネル
深さ虚時間E₀E₁E₂E₃E₄
5,0000.24.077.5515.2618.8119.51
20,0000.83.0398.36012.69516.05518.664
100,0004.03.03728.361412.685716.010118.3347
厳密3.03738.361812.686416.010918.3355

残る \(10^{-3}\) の差は格子幅による離散化誤差。上の準位ほど多くの層が要るのは、混ざった成分が \(e^{-(\text{準位差})\,\tau}\) でしか消えないから。必要な深さを決めるのは無次元量 準位差 × 虚時間。第1回 の「虚時間 = 逆温度」から見れば、深い CNN とは冷やしていく装置である。

033 次元：水素原子と、壊れる対称性

3×3×3 の畳み込み（6 近傍のラプラシアン）と \(-1/r\) の積で、同じことを 3 次元でやる。格子は 128³、格子幅 0.5 bohr、15 チャンネル、12,000 層（虚時間 840）。原子核は立方体の中心に置き、格子の対称性（立方群 Oh）が原子核のまわりで厳密に保たれるようにした。

本物の水素では、\(n\) が同じなら \(\ell\) によらず縮退する（2s と 2p、3s・3p・3d）。これは回転対称性 SO(3) より大きい、クーロン力に特有の隠れた対称性 SO(4) による「偶然」の縮退である。格子はそれを二段階で壊す。

  • SO(4) が壊れる：s 状態だけが大きく持ち上がる（1s は 0.026、2s は 0.0023）。s 状態だけが原子核の位置で 0 にならず、格子の上では \(-1/r\) の特異点が均されて浅くなるからである。準位は \(\ell\) ごとにずれ、2s と 2p、3s と 3p と 3d が割れる。
  • SO(3) → Oh：p は 3 重のまま残る（T1u は 3 次元の既約表現なので割れようがない）。d の 5 重は、立方体の群では一つの既約表現に収まらず 2 + 3（Eg + T2g）に割れる。分裂幅は \(4.2\times10^{-5}\) Ha。
核心：チャンネル = 既約表現
d 軌道が eg と t2g に割れるのは、化学でいう結晶場分裂と同じ群論である。CNN の格子は、原子にとって「立方体の結晶場」として働く。チャンネルに出てきた固有状態は、格子の対称群の既約表現でラベル付けされる。分子スペクトルの縮退も素粒子の多重項も既約表現なので、CNN とはこの群論の線でつながる。

04格子ゲージ理論：対称性は学習の前提

素粒子の標準模型を計算機で解く格子 QCD は、格子の辺（リンク）に位相を置いた場の理論である。最小版の 2 次元 U(1)（格子 QED）では、ウィルソンループが厳密に解ける。

$$\langle W(R\times T)\rangle = \left(\frac{I_1(\beta)}{I_0(\beta)}\right)^{RT}\qquad\text{（面積則 = 閉じ込め、弦張力 } \sigma = -\ln\tfrac{I_1}{I_0}\text{）}$$

05学習する波動関数：ヘリウム原子

第1〜4回 の CNN は重みが固定で、中身は差分法だった。電子が 2 個以上になると、格子は次元の数だけ指数的に大きくなり、この方法は使えない。そこでネットワークを試行関数にして学習させる（変分モンテカルロ、FermiNet・PauliNet の系統）。

$$\ln\psi = -Z(r_1+r_2) + \frac{r_{12}}{2(1+b\,r_{12})} + \mathrm{NN}(r_1, r_2, r_{12})\quad\text{（電子の入れ替えで対称化）}$$

補足：第1回 の線がここにも通る
VMC でエネルギーを下げる勾配は \(\nabla E = 2\langle (E_L - \bar E)\,\nabla\ln\psi\rangle\)。「エネルギーとスコア関数の共分散」であり、Price の式 \(\Delta\bar z = \mathrm{Cov}(w,z)/\bar w\) や ES の勾配と同じ形をしている。サンプリングはメトロポリス法、つまり 第1回 の「温度」の線そのもの。

07正直な線

どこで線が切れるか
  • 「CNN で計算できる」には二つの意味がある。 第1〜4回 前半は重みが固定で、計算の構造が CNN の形をしているだけ（中身は差分法と虚時間発展法という古典的な数値計算）。学習が本当に効くのは 04 後半と 05 だけ。
  • 第5回 のネットワークは CNN ではなく MLP。 電子の座標は格子に乗っていないので、畳み込みの出番がない。分子で使われるのは、畳み込みを回転群に一般化した同変ネットワーク（SchNet、NequIP、MACE）。
  • eg と t2g の上下を本物の結晶場と比べてはいけない。 ここで割っているのは配位子の電場ではなく格子の離散化誤差なので、同じ群論でも分裂の符号と大きさの物理は別物。共通なのは「何本に割れるか」だけ。
  • 普通の CNN が学べなかったのは、この学習量での話。 原理的にはプラケットの組み合わせを自分で発見できるはずで、データと時間を増やせば学べる可能性はある。
  • 新しくはない。 虚時間発展、結晶場の群論、2 次元 U(1) の厳密解は教科書。L-CNN は Favoni ら (2022)、ニューラル試行関数は Carleo–Troyer (2017)、Pfau ら (2020) ほか。
まとめ
  • カーネルは分散関係、深さは虚時間、チャンネルは既約表現、格子の対称性は結晶場。CNN の部品には全部、物理の名前が付いている。
  • 同じカーネルでも、時間 1 階なら拡散（二次の換算）、2 階なら波（一次の換算）。第1回 の「換算の形」は時間微分の階数で選ばれる。
  • 深い CNN は冷やす装置で、スペクトルは「準位差 × 虚時間」の順に出てくる。
  • 対称性を組み込むことは、ゲージ理論では学習を成立させる前提だった。
  • 相互作用のある多体系では、学習するネットワークが試行関数になる。その勾配は Price の式や ES と同じ共分散の形。
