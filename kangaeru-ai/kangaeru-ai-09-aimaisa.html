曖昧さが物理量になる 安定な井戸でも級数は曖昧で、負の確率は一層で生まれる

2026-10-27 ／ 第8回の末尾の二本を掘る。Zinn-Justin の二重井戸と、Moyal 方程式の ħ² 項。検証は付録に
四行の要約
  1. 崩壊しない系でも、摂動級数は曖昧である。 二重井戸の係数は全部同じ符号で、Borel 和は正の結合定数でも虚部を持つ。
  2. その虚部はインスタントン対の大きさで現れる。 指数 −1/(3g)、大きさ (π/4)ΔE² の 1.1 倍。真のエネルギーが実なのは、級数の虚部とインスタントン対の虚部が相殺するから（Zinn-Justin）。
  3. 負の確率を作るのは、Moyal 方程式の ħ² の一項だけ。 古典流（Liouville）は正の分布を正に保ち、量子の再帰を失う。三階微分の一層を足すと、負の値が生まれ、再帰が戻る。
  4. 第8回と合わせて、三つの「曖昧さ」が揃った。 崩壊率（不安定な級数の虚部）、インスタントン対（安定な級数の虚部）、位相（負の確率）。どれも「正の実数で閉じない部分」の名前である。

01安定な井戸の級数は、それでも曖昧

第8回の非調和振動子では、g > 0 で級数は Borel 可和、g < 0 で曖昧になり、曖昧さが崩壊率だった。二重井戸 V = x²(1 − √g x)²/2 は g > 0 で安定だが、摂動級数の係数が全部同じ符号になる。

計算Rayleigh–Schrödinger 漸化式（V₁ = −x³ が √g の一次、V₂ = x⁴/2 が二次）、70 次まで、60 桁精度

奇数次は厳密に 0（E は g の関数だから）。e_k = 0.5, −1, −4.5, −44.5, −626.6, −11031, …、e₃₅/e₃₄ = 105 ≈ 3k。全部負なので Borel 変換の特異点は t = +1/3 の正の実軸上にあり、ラプラス積分がそれを跨ぐ。安定な系なのに和が一意に決まらない。

積分路を特異点の上と下に避けた二つの側方 Borel 和は、虚部の符号が逆の複素数になる。真の基底エネルギーは実数なので、この虚部を打ち消す何かが要る。それがインスタントン対（インスタントンと反インスタントン）の寄与で、その実部は ln g を含み、虚部は級数の虚部とちょうど逆符号になる、というのが Zinn-Justin (1981) の主張である。

核心
摂動級数は二つの準位の平均を、曖昧さ e^{−1/(3g)} の精度で与える。一インスタントンが準位を分裂させ（e^{−1/(6g)}）、インスタントン対が級数の曖昧さを埋める（e^{−1/(3g)}）。崩壊しない系でも、級数の曖昧さは非摂動の寄与の正確な入れ物である。

02負の確率はどこで生まれるか

第8回で、拡散が量子になれないのは負の確率を持てないからだと書いた。では負の確率はどこで生まれるか。Wigner 関数の時間発展は Moyal 方程式

$$\frac{\partial W}{\partial t} = -p\,\frac{\partial W}{\partial x} + V'(x)\frac{\partial W}{\partial p} - \frac{\hbar^2}{24}V'''(x)\frac{\partial^3 W}{\partial p^3} + O(\hbar^4)$$

で、四次ポテンシャルでは ħ² で打ち切った形が厳密である。最初の二項は古典の Liouville 方程式（位相空間の流れ）で、正の分布を正に保つ。負の値を作れるのは三番目の項だけで、これは p 方向の三階微分、つまりカーネル [−1, 3, −3, 1]/dp³ の畳み込み一層である。

計算V = x²/2 + 0.1x⁴、x₀ = 1.5 のコヒーレント状態。Moyal と Liouville は分割演算子法（位相を厳密に）、量子力学は Schrödinger 方程式を別の格子で

  • Liouville は t ≈ 10 以降で量子力学から離れ、⟨x⟩ が 0 に潰れる。 非調和性で位相空間の分布がぐるぐる巻きになり（古典的な位相のずれ）、平均が消える。
  • Moyal は再帰を保つ。 t = 24 で ⟨x⟩ = −0.27（Schrödinger −0.24）。ずれは格子と分割の誤差。
  • 負の値は ħ² 項が作る。 Moyal の min W は −0.15 〜 −0.27、Liouville は −0.05 以下（スペクトル法の数値的な振動で、物理ではない）。

第2回の「深さ = 時間の CNN」で言えば、量子と古典の違いは一層のカーネルの違いである。古典流のカーネル（一階微分）に三階微分のカーネルを一つ足すと、負の確率が生まれ、再帰が戻る。第8回の「節 = 負の確率」の、生成の側の話がこれになる。

04正直な線

どこで線が切れるか
  • 二重井戸の係数 1.1 と 1.4 は「定数まで一致」ではない。 O(g) の補正を追っていない。確かめたのは指数と桁、そして相殺の構造まで。Zinn-Justin–Jentschura の厳密な予想（級数とインスタントン展開を全次数で結ぶ関係式）の検証には、もっと小さい g と高次の係数が要る。
  • Moyal の ⟨x⟩ は Schrödinger と 0.03〜0.1 ずれる。 位相空間の格子（160²、箱 ±5）と分割の二次の誤差。t = 2 で 7% のずれがあり、格子を倍にして確かめるべきだが、今日はしていない。
  • Liouville の min W が −0.05 まで落ちるのは数値的な振動。 スペクトル法は正値性を厳密には保たない。物理的な負値 −0.2 とは桁が違うので結論は変わらないが、「厳密に 0」ではない。
  • 最初の二つの版は壊れていた。 Runge–Kutta では三階微分の項が硬すぎて発散し（CFL）、分割演算子法に書き直した。さらに係数の配列を誤って三次元に広げ、一歩 0.5 秒かかっていた。どちらも直してから出した数値である。
  • 「三つの曖昧さは同じ型」は語り。 負の確率と Borel 可和性を結ぶ定理は知らない。
まとめ
  • 二重井戸の級数は安定でも曖昧で、曖昧さはインスタントン対の大きさ（e^{−1/(3g)}、(π/4)ΔE² の 1.1 倍）。真のエネルギーが実なのは相殺の結果。
  • 負の確率は Moyal 方程式の ħ² の三階微分項、つまり一層のカーネルが作る。古典流は正値を保ち、再帰を失う。
  • 崩壊率、インスタントン対、位相。三つとも「正の実数で閉じない部分」の名前。
