## 🔧 姉妹シリーズ「物理を作る」

「わかる」が**既知の物理を解説する**シリーズなのに対し、こちらは立場が逆になります ── 空白や「怪しい数」に対して**道具を作り、走らせ、出た結果をそのまま読む**。うまくいかなかった回も、**自分が間違えた回も**、そのまま載せます。主役は結論ではなく、作業のほうです。

背骨は一文 ── **物理を作るとは、予想することではなく、予想が死ぬ条件を先に作ることである。**

| シリーズ | 内容 | 読む（公開サイト）|
|---|---|---|
| **物理を作る 第1部** | 空白に道具を作って走らせる。無次元量を16万本総当たりして偶然しか出ないことを測る（p=0.67）→ 時空を格子にすると18桁のファインチューニング → 舞台は平坦でよい（等価原理が結論として出る）→ 重力波の記憶効果と BMS → 境界は3次元だった（光速ゼロの Carroll 幾何）→ ソフト定理の塔が w(1+∞) をなす→ 地平面も Carroll → 何が無いのかを仕様として詰める → 3次元では、もう証明されている → **BMS₄ に中心電荷は無い**（dim H²=0 を自分で計算）→ 面積則はただで出る → 自由度は数えなくてよかった → **壁は第1回の定理だった** → 平坦な格子で水星が回る（**42.9807″/世紀**、GR比 1.0000）→ 決着は光子1個（**112 PeV**）→ こっちのほうが計算が楽だ。**閉まった扉4枚・通った計算1つ・反証可能な数字1つ・新しい物理0**（全19話＋番外3話・完結）| [開く](https://yomei-o.github.io/wakaru_all/butsuri-tsukuru/index.html) |
| **物理を作る 第2部 ── その数は、偶然か** | すでに世の中にある「妙にきれいな数」を一つずつ裁く。**Koide 編**：荷電レプトンの質量が Q=2/3 を満たすのは「質量ベクトルが対角線に対して **45度**」の主張（ずれ 9.5×10⁻⁵ 度）→ 統計では決まらない（同じ族を乱数に当てると **51%** で何か当たる）→ 決めたのは年表と由来（1982年に 1.76σ 外れていた予言にデータが 7 MeV 寄った。ただし著者自身が一度パッチしていた）→ **対称性では原理的に導けない**（S₃ 不変量が代数的に独立だから）→ 質量ベクトルは 1+2 で**光的**＝三つの質量が二つの実数から出る → 模型が要求する族ゲージ粒子は**六個**で比に自由パラメータ0 → その予言 K⁺→π⁺μ⁺e⁻ は**既存上限の 75%**、排除に露光 1.7倍。**ところが誰も測っていない**（全8話）| [開く](https://yomei-o.github.io/wakaru_all/butsuri-tsukuru2/index.html) |
| **物理を作る 第3部 ── まだ、測られていない** | 測定の側を見る。**誰の計画にも入らないまま、決着可能なまま残っている測定**を探す。出発点は第2部の K⁺→π⁺μ⁺e⁻（露光 1.8倍で決着するのに誰も測っていない）── ところが第1回で前提が崩れる：**模型は放置されていない**（μ-e 転換の建設中の実験が全パラメータ空間を覆う）。ただし必要な改善は 1.2×10⁴ 倍で、K 崩壊の 1.8倍と比べて **6500倍**。それでも不合理ではなく、**選ばれる基準は安さではなく「広さ」**だった → だから体系的に落ちるのは**狭くて安い測定**。第2回で PDG の K⁺ を全9本並べたら**その読みも逆転**：最強の上限 1.3×10⁻¹¹ は NA62 が触らなかったモードに付いていた（NA62 の2本は 3.2倍・5.1倍弱い）。理由は E777／E865 の**専用実験が16年**あったから → 狭いモードは「落ちる」のではなく**「凍る」**。第3回で一次資料（Barker & Kettell 2000）を開くと**止めた理由まで書いてあった** ── 背景の壁（K_L→μe は 10⁻¹³ が床、K⁺→π⁺μ⁺e⁻ は偶発背景）。床の位置が分かるので残る土地が計算できる：分岐比 47倍＝**質量スケールで 2.62倍**（150→393 TeV）、それが永久に残された全部。一方 μ→eee は**38年**凍っていたが壁ではなく、Mu3e が質量 8.41倍を取りに来る → **凍結年数は指標にならない**（第3回まで公開・訂正18件目）| [開く](https://yomei-o.github.io/wakaru_all/butsuri-tsukuru3/index.html) |

各話に**動く図**つき。検算コードは純 C++／純 Python・依存なし（[kuuhaku_cpp](https://github.com/yomei-o/kuuhaku_cpp)）。

**負の結果は負のまま、訂正は隠さず載せています** ── 訂正バナー＋台帳を各話に付けており、Koide 編だけで **15件（保守4・中立3・不利8）**。「良くなったから開いてよかった」ではなく「向きが読めないから開く」が方針です。

## 構成メモ
- 各シリーズは**このリポジトリ直下の兄弟フォルダ**として置いています。目次どうしは相対リンクで姉妹編を参照します（例：`wakaru-ba/` の目次 → `../wakaru-chikara/index.html`）。だから各シリーズは直下の兄弟フォルダに置いてください。
- 物理4部作（場・相対論・量子・宇宙論）は、基本定数 c・ℏ・G で一枚につながります（→ [物理の立方体](butsuri-rittai.html)）。「単位のある量は舞台装置、効くのは無次元の比」が全集を貫く視点です。
