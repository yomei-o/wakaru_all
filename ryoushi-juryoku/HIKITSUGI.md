## 2. 今日いちばん足りていないこと（次の一手）

優先度順。①は必ずやってください。

### ① T を変えた対照実験（最優先）
経験則 \(A\bar n = C q^3\)（\(C\approx3.9\)）は **すべて T=32 で取っています**。
T=16 と T=64 で同じ \(C\) が出るかを確かめないと、法則と呼べません。

```
./cdt3d_mc.exe 16 6 1.0 0.0 45000 59 200000 16000 3e-4
./cdt3d_mc.exe 16 6 1.0 4.0 45000 59 200000 16000 3e-4
```

**注意**: \(\bar n = N_{31}/T\) なので T を変えると \(\bar n\) も変わります。
それを込みで \(C\) が動かなければ本物です。

### ② 指数 3 の理由を考える
\(q\) は (2,2) 四面体の**全四面体に対する割合**。なぜ三乗なのか。
素朴には運動項は (2,2) の数に比例（一乗）しそうなのに、そうならない。
ここが今日いちばん面白い未解決点です。

### ③ N=32,000 の統計を上げる
今の値 \(C = 4.252 \pm 0.306\) は掃引 22000 で、他（30000〜90000）より少ない。
上振れしている可能性が高い。60000 掃引で取り直す。

### ④ 空間を球面 \(S^2\) にする
今はトーラス。4次元 CDT で有名な de Sitter 的な「こぶ」は
球面トポロジー＋非周期時間でないと原理的に出ません。
初期配位の作り方を変えるだけ（プリズム分解は球面でもそのまま使える）。

### ⑤ \(k_0\approx6\) の転移らしきものを詰める
感受率にピークの気配はあるが統計が薄い。有限サイズスケーリングが要ります。

## 3. 踏んだ罠（3次元で新しく踏んだもの）

2次元の罠は MEMO.md にあります。ここには3次元固有のものだけ。

1. **swap-remove が四面体を採番し直す。**
   局所手術のために「外側の面 → 隣の四面体」の番号を控えてから四面体を消すと、
   控えた番号が古いままになる。開面だらけになって χ=30 になりました。
   → `del_tet(G, k, &ext)` のように **ext を渡して同時に付け替える**。

2. **隣接ポインタを手で張り替えない。**
   面をキーにした `relink()` で貼り直すほうが、添字の場合分けより圧倒的に安全。
   3次元は場合分けが多すぎて手では追えません。

3. **消してから失敗すると復元できない。**
   新しくできる四面体の型は **全部消す前に確定**させる。
   `move26` で最初これを間違えて、失敗時に壊れた複体が残る書き方をしていました。

4. **`(2,3)/(3,2)` だけでは熱力学極限が無い。**
   頂点が凍るとエントロピーが指数的にならない。臨界点を探しても見つかりません。
   → `(2,6)` が本体。

5. **分離相（大きい \(k_0\)）は緩和が異常に遅い。**
   \(k_0=6,8\) で 20000 掃引だと個々の \(C(d)\) が桁で振れます。
   平均は正しい値（\(-1/(T-1)\)）に乗るので、**個別の \(d\) を信じない**こと。

6. **ヒアドキュメント（bash の `<<'EOF'`）で C の `\n` が潰れる。**
   `printf("...\n")` を含むパッチは **Edit ツールで当てる**。
   今日これで4回以上ビルドが壊れました。

## 5. シリーズ全体の「越えられなかった線」

- 当初の目標「人間が気づいていない物理の法則を導出する」は **達成していません**。
  出たものはすべて既知か、既知から自明に出るものです。
  唯一の候補は \(A\bar n \approx 3.9\,q^3\) ですが、
  T の対照が無く、指数 3 の理由も分かっていないので**まだ何とも言えません**。
- 2次元は「共形モードだけを取り出した実験」であって、4次元の共形因子問題そのものではない。
- 3次元でも連続極限の話は一切していません。系が小さすぎます。
- \(\langle l(t)\rangle = t+1\) は形は \(R_h = ct\) ですが**2次元の話**です。
  「わかる共形変換」番外編の BBN 判決は一文字も変わりません。ここは越えないこと。
