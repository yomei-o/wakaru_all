01導く前に、標的を書き直す

導出に挑むとき最初にやることは、標的を一番扱いやすい形に書き直すことです。\(2/3\) という数字のままでは手がかりが少なすぎます。

質量の平方根を並べたベクトルを \(v_i=\sqrt{m_i}\) と書きます。第1回で見たとおり、Koide 関係は \(v\) と対角線 \((1,1,1)\) のなす角が \(45^\circ\) だという主張でした。これを二次形式に書き換えます。

\(J\) を全成分 1 の 3×3 行列、\(I\) を単位行列として

$$F(v)=\tfrac{2}{3}\Bigl(\sum_i v_i\Bigr)^2-\sum_i v_i^2 \;=\; v^{T}\eta\,v,\qquad \eta=\tfrac{2}{3}J-I$$

とおくと、\(Q=\dfrac{\sum m}{(\sum\sqrt m)^2}=\dfrac{2}{3}\) は \(F(v)=0\) と完全に同値です。

ここで \(\eta\) の固有値を見ます。\(J\) の固有値は \((3,0,0)\) なので、\(\eta\) の固有値は

$$3\cdot\tfrac{2}{3}-1=+1,\qquad -1,\qquad -1$$

符号数が \((+,-,-)\)。つまりフレーバー空間には 1+2 次元のミンコフスキー計量が乗っていて、Koide 関係が言っているのは一言でこうなります。

質量の平方根ベクトルは、光的（lightlike）である。

数え合わせが合っているか確かめます。1+2 次元の光円錐は2次元の面です。だから光的な \(v\) は2つの自由度しか持たず、それが3つの質量を決める ── これは Koide の2パラメータ表示そのものです。

\(\sqrt{m_i}=A\bigl(1+\sqrt2\cos(\theta+2\pi(i-1)/3)\bigr)\) と書くと、\(\sum\cos=0\) と \(\sum\cos^2=3/2\) から

$$\sum\sqrt m=3A,\qquad \sum m=A^2\Bigl(3+\tfrac{3}{2}\cdot 2\Bigr)=6A^2 \;\Longrightarrow\; Q=\frac{6A^2}{9A^2}=\frac{2}{3}$$

となり、\(\theta\) が何であっても \(Q=2/3\) が恒等的に成り立ちます。
つまり \(Q=2/3\) は追加の仮定ではなく、「3つの質量が2パラメータの形に収まる」という主張そのものです。

ここまでで、同じ一つの条件に5つの名前がついたことになります。実測値を全部入れておきます。

ただし、この二つを同種のものとして扱ってはいけません（訂正⑫）。\(\theta_{23}\) の「半分」は \(\mu\leftrightarrow\tau\) という交換対称性から出ます ── 1次元の部分空間を1次元の部分空間に写す等長写像があるからです。いっぽう \(\langle P\rangle=1/2\) は \(\mathbf{1}\) と \(\mathbf{2}\) の間の等式で、次元が違うので写す写像そのものが存在しません。交換対称性の機構は、ここでは使えません。この 50:50 を起こしているものが何なのかは、誰も知りません。

02なぜ \(2/3\) なのか ── 鏡だけが残る

ここが今回の芯です。\(2/3\) を一般化して \(\eta_Q=QJ-I\) と書いてみます。固有値は \((3Q-1,\,-1,\,-1)\)。

この形式に「鏡映であれ」という条件、つまり \(\eta^2=I\) を課します。二回かけると元に戻る ── 反転（involution）です。

$$(3Q-1)^2=1 \;\Longrightarrow\; 3Q-1=\pm1 \;\Longrightarrow\; Q=\frac{2}{3}\ \ \text{または}\ \ Q=0$$

非零解は \(2/3\) だけ。そして実際に

$$\eta=\tfrac{2}{3}J-I=2P-I,\qquad P=J/3$$

これは対角線軸まわりの鏡映そのものです。数値で確認：

\(v^{T}(2P-I)v=0\) を言葉にすると、「\(\sqrt m\) を対角線軸で鏡に映すと、元のベクトルと直交する」。45 度で入って 45 度で出るから合わせて 90 度 ── 当たり前の言い換えです。当たり前なのに、こちらの方が導出しやすい形になっています。理由はこうです。

問いの種類が変わりました。

「なぜ \(45^\circ\) なのか」は連続量の一致を問う質問です。
「なぜ形式が鏡映なのか」は離散的な代数条件（\(\eta^2=I\)）を問う質問です。要求の形が、連続量の値から整数的な代数の性質に変わりました。

初出時、私はここに「離散条件は、対称性が強制できる種類のものです」と書きました ── 誤りです（訂正⑫）。\(\sum v\) と \(\sum v^2\) は代数的に独立な \(S_3\) 不変量なので、対称性はこの二つの間に関係を課せません。対称性が決められるのは「どの不変量が存在するか」までです。
したがって \(\eta^2=I\) を要求できるのは対称性ではなく、力学（ポテンシャルの最小値）か、フレーバー空間より大きい空間の対称性の二つだけです。

導出の難易度が下がったとは言いません。難易度の種類が変わり、行き先が2つに絞られました。

05截断からは、出ない

ここで別方向から攻めます。「時空に最小単位がある」「宇宙は有限リソースの計算機である」から質量が出る、という筋です。第1部第2回で格子を扱ったので、続きとして自然な方向です。

結論を先に書きます。この筋で \(Q=2/3\) は出ません。理由は一行です。

\(Q\) は質量の 0 次同次関数です。つまり質量を全部同じ倍率でスケールしても \(Q\) は微動もしません：\(\sum_i \partial Q/\partial\ln m_i=0\)（厳密に 0）。

koide_rg.py ── 0次同次の確認 
  Q(lambda*m), lambda=  1e-06 : 0.666664463414500
  Q(lambda*m), lambda=  1e+00 : 0.666664463414500
  Q(lambda*m), lambda=  1e+06 : 0.666664463414500

  sum_i dQ/dln m_i = +0.000e+00
  dQ/dln m_e = -0.008786   dQ/dln m_mu = -0.091531   dQ/dln m_tau = +0.100317

質量比は無次元量です。無次元量に截断 \(\Lambda\) が入るには \(\ln(\Lambda/\mu)\) のような無次元の組合せを通るしかありません。そして QED・QCD の1ループ質量異常次元はフレーバーに依らないので、走り（くりこみ群の流れ）は \(Q\) から丸ごと消えます。

残るのはフレーバー依存する項だけ。荷電レプトンではそれは湯川の自己項 \((3/2)y_i^2\) だけで、\(y_\tau^2=1.04\times10^{-4}\) と小さい。実際に走らせると：

\(M_Z\) からの e-fold\(m_\tau/m_\mu\)相対変化
016.8176920
1016.817858\(+9.9\times10^{-6}\)
39.4（\(M_Z\to M_{\rm Pl}\)）16.818345\(+3.9\times10^{-5}\)

電弱スケールからプランクスケールまで 39 e-fold 走らせて、質量比は \(4\times10^{-5}\) しか動きません。比は理論の定数であって、截断の関数ではない。

だから問題は二つに分かれます。

問題1（スケール）：そもそも質量があるのはなぜか。── これは解けています。純ヤンミルズは質量パラメータを一つも持たないのに \(\Lambda=\mu\,e^{-2\pi/\beta_0\alpha_s}\) で質量を作り、格子で測ると最軽グルーボールは 1.73 GeV。「截断から質量が出る」は 1973 年に本当に成功しています。

問題2（比）：なぜこの数値なのか。── これは開いていて、截断の話が原理的に届きません。

この二つを混ぜると「宇宙が有限の計算機だから質量公式ができる」という文になりますが、混ざりません。

有限リソースの側にも、当たりが一つあります

公平に書いておきます。「有限の情報量」から出る量で、実際に当たっているものがあります ── 真空エネルギーです。
Cohen–Kaplan–Nelson (1999) は「大きさ \(L\) の箱の有効理論に、すでにブラックホールになっている状態を入れてはいけない」というまさに有限リソースの要求から \(\rho_{\rm vac}\sim M_{\rm Pl}^2H_0^2\) を導きます。数を入れると

  observed   rho_Lambda^(1/4)  = 2.2404e-03 eV
  predicted  sqrt(M_Pl,red*H0) = 1.8712e-03 eV   ratio = 0.84

素朴な場の理論が \(10^{120}\) 外す量を、数え上げだけで係数 1.2 以内。有限リソースという発想の一番強い成果はこれで、質量公式ではありません。
ついでに ── 有限リソースが与える最小エネルギーは地平面から \(\hbar H_0=1.44\times10^{-33}\) eV です。ニュートリノ質量 0.05 eV より31桁下なので、「ニュートリノが最小のビット」という読み方は成り立ちません。

06そして式は、極質量に固定されている

導出を難しくしている事情がもう一つあります。この式が、どの質量の定義について成り立っているかという問題です。

PDG が与えるのは極質量（on-shell 質量）です。いっぽう高いスケールの模型が自然に与えるのはくりこみ質量（\(\overline{\rm MS}\)）。両者は1ループ QED でつながります。

$$\bar m_i(\mu)=M_i\Bigl[1-\frac{\alpha}{4\pi}\Bigl(4+3\ln\frac{\mu^2}{M_i^2}\Bigr)\Bigr]$$

\(\ln\mu^2\) の項はフレーバーに依らないので \(Q\) から消えます。消えないのは \(3\ln M_i^2\) の項で、これは質量を \(m\to C\,m^{1+b}\)、\(b=3\alpha/2\pi=3.48\times10^{-3}\) とべきで傾ける操作です。\(Q\) はべき傾けには不変ではありません。
